이 작업을 오늘부터 6일간 매일 1회, 오전 10시에 예약 실행해라. 브라우저에는 네이버 계정이 로그인되어 있다.

[매일 실행 절차]
1. https://searchadvisor.naver.com 접속 → 웹마스터 도구에서 사이트 "https://ezspeak.vercel.app" 선택
2. 왼쪽 메뉴 [요청] → [웹 페이지 수집] 화면으로 이동
3. 아래 전체 URL 목록에서 **아직 처리하지 않은 첫 번째 URL부터 순서대로 최대 50개**를 처리한다. 어디까지 처리했는지 매일 기억해두고, 다음 실행 때 그 다음 URL부터 이어서 진행해라:
   - 입력창에 URL 전체를 붙여넣고 [확인] 클릭
   - 성공 메시지 확인 후 다음 URL로
   - "이미 요청된 URL" 안내가 나오면 처리된 것으로 간주하고 다음으로 (재시도 금지)
4. 다음 상황에서는 그날 작업을 즉시 멈추고 나에게 보고해라 (계속 시도 금지). 단 예약 자체는 유지해서 다음 날 이어가라:
   - "일일 요청 한도 초과" 안내 (몇 번째 URL까지 성공했는지 보고)
   - 캡차(자동입력 방지) 등장
   - 같은 오류 2회 연속 반복
5. 매일 실행이 끝나면 "Day N: 성공 ○건 / 중복 ○건 / 실패 ○건 (실패 URL), 전체 진행률 ○/254" 형식으로 보고해라
6. 전체 254개가 모두 처리되면 예약을 종료하고 최종 요약을 보고해라

[금지사항]
- 수집 요청 메뉴 외 다른 조작(설정 변경, 사이트 삭제, 소유확인 재설정 등) 절대 금지
- 하루 50개를 넘겨서 요청하지 마라
